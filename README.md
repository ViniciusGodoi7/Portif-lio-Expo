# Meu Portfólio

## Sobre o projeto

Este projeto é um portfólio pessoal desenvolvido utilizando React Native e Expo como parte dos meus estudos em Desenvolvimento de Sistemas no SENAI.

O objetivo é apresentar algumas informações sobre mim, mostrar meu curso e facilitar o acesso ao meu perfil no GitHub.

## Tecnologias utilizadas

- React Native
- Expo
- TypeScript
- JavaScript
- Visual Studio Code

## Funcionalidades

- Exibição da foto de perfil.
- Apresentação do nome e do curso.
- Botão para acessar meu perfil no GitHub.
- Menu superior com links.

## Como executar o projeto

### 1. Clonar o repositório

```bash
git clone URL_DO_SEU_REPOSITORIO
```

### 2. Entrar na pasta do projeto

```bash
cd meu-portfolio
```

### 3. Instalar as dependências

```bash
npm install
```

### 4. Iniciar o Expo

```bash
npx expo start
```

Para abrir o projeto no navegador, pressione a tecla `w` no terminal.
